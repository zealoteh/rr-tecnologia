A imagem de treinamento é uma cena fictícia gerada por IA para o piloto e está identificada como ilustrativa. Substitua assets/treinamento.png para utilizar outra imagem e ajuste o texto alternativo no HTML se necessário.

## Edição
index.html contém os textos. assets/app.js contém os seis passos da demonstração, os controles e as animações. assets/styles.css é o CSS pronto. src/input.css é a origem dos estilos. Para recompilar opcionalmente: npm install e npm run build.
