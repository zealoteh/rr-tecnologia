# RR — Tecnologia & aprendizado — apresentação

## Abrir
Extraia o ZIP e abra `index.html` no navegador. Mantenha a pasta `assets` ao lado do HTML. Não é necessário instalar npm, Python ou banco de dados.

A página inclui apresentação do serviço, etapas de trabalho, demonstração interativa de um plano ilustrativo, estratégias, avaliação prática, entregas e perfil profissional. O exemplo é demonstrativo e não representa um diagnóstico realizado em uma empresa.

## Editar
- `index.html`: textos e estrutura.
- `assets/app.js`: demonstração e interações.
- `src/input.css`: estilos de origem.
- `assets/styles.css`: estilos já compilados, usados pelo navegador.

Somente para recompilar os estilos após editar `src/input.css`, instale Node.js/npm, execute `npm install` e depois `npm run build`. Não é necessário recompilar para alterar apenas os textos do HTML ou do JavaScript.

## Publicação
Este pacote ainda não foi publicado. Para uma hospedagem estática, envie `index.html` e a pasta `assets`, mantendo os caminhos relativos. Identidade e contato podem ser ajustados antes da publicação. O site não envia formulários nem armazena dados de visitantes. Os links de fontes precisam de internet.

## Verificação
Navegação da demonstração e abertura do plano conferidas no navegador desktop. Layout com regras responsivas e preferência por movimento reduzido; recomenda-se conferir em um celular real antes da publicação.

Títulos, subtítulos e elementos de apoio entram suavemente ao aparecer na tela, uma vez por carregamento. A preferência do dispositivo por movimento reduzido desativa essas transições.
